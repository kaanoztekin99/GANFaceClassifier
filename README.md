# GANFaceClassifier

A CNN-based framework for detecting GAN-generated human faces and identifying their source architecture.

This project was developed as part of the **DT068A Image Analysis** course at **Mid Sweden University (Mittuniversitetet)**.

---

## Project Overview

Recent advances in Generative Adversarial Networks (GANs) have enabled the creation of highly realistic synthetic human faces. While early GAN architectures often produced visible artifacts, modern models such as StyleGAN2 and StyleGAN3 can generate images that are increasingly difficult to distinguish from real photographs.

The goal of this project is to investigate whether a Convolutional Neural Network (CNN) can:

1. Distinguish real faces from GAN-generated faces.
2. Identify which GAN architecture generated a synthetic face.

The project focuses on a multi-class classification problem involving real images and faces generated by different GAN architectures.

---

## Dataset

### Real Images

* CelebA Dataset

### Synthetic Images

* DCGAN (2015)
* Progressive GAN (PGAN, 2017)
* StyleGAN2 (2020)
* StyleGAN3 (2021)

The dataset was balanced to contain an equal number of samples from each class.

### Classes

| Class ID | Label     |
| -------- | --------- |
| 0        | Real      |
| 1        | DCGAN     |
| 2        | PGAN      |
| 3        | StyleGAN2 |
| 4        | StyleGAN3 |

---

## Methodology

### Data Preprocessing

The following preprocessing steps were applied:

* Image resizing to 224×224 pixels
* Random horizontal flipping
* Small random rotations
* ImageNet normalization

Dataset split:

* Training: 80%
* Validation: 10%
* Test: 10%

---

## CNN Architecture

The classifier consists of:

* 5 convolutional blocks
* Batch normalization
* ReLU activation
* Max pooling
* Dropout regularization
* Fully connected classification layers

The network was trained using:

* Adam optimizer
* Cross-Entropy Loss
* Early Stopping

---

## Results

The trained model achieved strong performance in distinguishing between real and synthetic faces.

Notable observations:

* Real faces were classified with very high accuracy.
* DCGAN images were the easiest synthetic images to detect.
* PGAN images were detected reliably.
* The highest confusion occurred between StyleGAN2 and StyleGAN3 images.
* Modern GAN architectures produce visually similar outputs that are significantly harder to distinguish.

Example evaluation outputs include:

* Training and validation curves
* 5-class confusion matrix
* Binary Real/Fake confusion matrix
* Classification reports
